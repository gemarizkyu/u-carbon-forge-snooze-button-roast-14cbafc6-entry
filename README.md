An entry for the **Snooze Button Roast** bounty on make.fun — a one-line comedic roast aimed at an alarm clock that dares to ring at 6 AM on a Saturday morning. Written in TypeScript, it runs offline with no network or model calls and always produces the same output.

## What it does

The script picks a fixed, pre-written roast line and writes it out as a single line of text — nothing random, nothing fetched, just a deterministic one-liner poking fun at the alarm clock.

## Run

```bash
node main.ts
```

This writes a single line to `/output/entry.txt`.
